\subsection{Technical Overview}
The system is built around an ESP8266 microcontroller, which serves as the central control unit for sensing, processing, and communication. The smart bin is equipped with sensors to monitor the fill level of the trash as well as environmental conditions, enabling the system to operate automatically and efficiently.\\
An embedded control system manages the different operational states of the bin, including monitoring, sealing, and standby modes. A full block digram of the system can be seen in Figure \ref{fig:hardware_block_diagram}

\subsection{Control System}
The control logic of the system is implemented as a state machine managed by the ESP8266. This approach ensures structured and predictable behavior across different operating conditions.\\
The system operates in four main states: \textit{LOAD}, \textit{CHECK}, \textit{CLOSE}, and \textit{EMPTY\_ME}. Each state defines a specific phase of the system’s operation.\\
In the \textit{LOAD} state, the system waits for the user to position the trash bag and press a button to initialize the process. Once the button is pressed, the system prepares the bag for normal operation and transitions to the next state.\\
In the \textit{CHECK} state, the system periodically measures the fill level of the trash bin at fixed time intervals of 15 minutes. Based on these measurements, the system determines whether the bin has reached a predefined threshold of 8cm or less.\\
When this threshold is reached, the system transitions to the \textit{CLOSE} state. In this state, the closing mechanism is activated to seal the trash bag.\\
After the bag has been sealed, the system transitions to the \textit{EMPTY\_ME} state. In this final state, the system waits for user input before preparing the bin for emptying and resetting the system for the next cycle.

\subsection{Mechanical Design}
The mechanical components of the system are based on a custom-designed 3D model of the trash bin.
The closing mechanism works by using two stepper motors to rotate two rollers with three O-rings on each. This mechanism pulls and releases the strings of the trash bag.
When activated, the motors rotate the rollers, and the friction between the O-rings and the strings pulls the strings in and closes the bag. The direction of rotation can also be reversed to loosen the strings when the trash bag needs to be removed.
The design keeps the closing/releasing mechanism compact while still allowing the rollers and motors to be aligned. Furthermore, the custom 3D construction allows for precise tolerances between the rollers and the stepper motors.
The 3D design also features a lid with mounting points and cutouts for attaching the ultrasonic sensor and the button used to control the embedded system.

\subsection{Communication and Notifications
}
The ESP connects to the local WiFi network and pushes all its data to ThingSpeak over HTTP. On the notification side we use IFTTT(IF This Then That: two ThingSpeak React rules watch field 4 (bag-full flag) and field 2 (bags remaining) and fire a push notification to the user's phone when the bag is full or when the stock drops below three. Setup is minimal — the user installs the IFTTT app, connects the ThingSpeak service once, and from then on gets notified without having to check the dashboard. It is not a sophisticated solution, but for a prototype it means the bin can actually reach the user when they are in another room
