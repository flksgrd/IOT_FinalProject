\textbf{Tasks carried out during the session:}
\begin{itemize}
    \item Anders added an SSD1306 OLED display and a temperature sensor to the bin. Started with a DHT11 (temp + humidity) but switched to a simpler LM35 (temperature only), and updated the ThingSpeak push to send the value on field 6.
    \item Jonas fixed the stepper pinout (moved IN4 from D1 to D0 so the OLED can use the I\textsuperscript{2}C SCL line) and adjusted the closing distance in \textsc{empty\_me}.
    \item The team calibrated the LM35 ADC reference voltage to 2.667\,V and added an IIR filter (10-sample average + 30/70 weighted blend) to smooth the temperature readings.
    \item The MOSFET added in the previous session was removed because it conflicted with the TX pin and broke serial logging. Instead the stepper coil pins are now pulled LOW after each move, giving the same idle-current saving without an extra component.
    \item Anders redesigned the web dashboard: translated the UI from Danish to English, added a temperature card with a thermometer SVG, and added a status pill that flips to \textsc{offline} when the ESP has not pushed data for $>$90\,s.
    \item Anders wrote an explainer document (\texttt{How the web dashboard works.md}) describing the ESP $\leftrightarrow$ ThingSpeak $\leftrightarrow$ dashboard flow for the rest of the team and the report.
\end{itemize}
