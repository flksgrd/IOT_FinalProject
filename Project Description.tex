\section{Project Description -- Smart Trash Bin}

\subsection{Purpose}
The purpose of this project is to develop a smart trash bin that prevents overfilling by automatically closing the trash bag at 80\% of the trash bag's capacity. The system also sends a notification to user when the bin needs emptying. It can also track the number of unused trash bags by deducting each automatic closure from the number of trash bags the user types in each time the user adds new bags to the storage.

\subsection{Functionality}
The system uses an ultrasonic sensor to measure how full the trash bag is. When the bin reaches around 80\%, a servo motor closes the bag by pulling the plastic strings that are attached to the bag's opening and a notification is sent, notifying the user that they have to empty the trash bin. The system keeps track of remaining bags and notifies the user when the number is low. It also monitors the time since the last emptying and sends a reminder if the trash bin has not been emptied for at couple of days to ensure that the content does not spoil (organic waste).

\subsection{System Components}
\begin{itemize}
    \item ESP8266 for control and Wi-Fi communication.
    \item Web server for data logging sending notifications
    \item Ultrasonic sensor for fill level measurement.
    \item Servo motor for automatic bag closing.
    \item Push button for reset after emptying.
    \item LCD or OLED display for status information.
    \item LDR, Photoresistor for analog sensing of light when the cabinet is opened.

    
\end{itemize}
